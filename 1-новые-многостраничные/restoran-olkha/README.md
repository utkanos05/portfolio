# «Ольха» — демо-сайт ресторана

Многостраничный сайт-образец для портфолио веб-разработчика: вымышленный авторский ресторан северной кухни в Москве, где всё готовят на ольховых углях.

> **Демо-сайт.** Ресторана не существует. Все названия, адреса, телефоны, имена и цены выдуманы.

## Что внутри

```
restoran-demo/
├── index.html      — главная: первый экран, «Сезонный круг», принципы, сет недели
├── menu.html       — меню с фильтром по категориям
├── about.html      — история, печь, команда
├── booking.html    — форма брони → WhatsApp с готовым текстом
├── contacts.html   — адрес, телефон, часы работы, нарисованная карта
├── css/style.css   — все стили сайта
└── js/main.js      — весь JavaScript сайта
```

Сборщики и зависимости не нужны: это обычные HTML, CSS и JS. Шрифты Cormorant Garamond и Manrope (оба с кириллицей) подключаются из Google Fonts. Все картинки нарисованы на SVG и CSS, фотографий нет.

## Как открыть сайт

**Самый простой способ:** дважды щёлкните по `index.html`, и он откроется в браузере.

**Через локальный сервер** (так сайт ведёт себя ближе всего к настоящему хостингу). В папке проекта выполните одну из команд:

```bash
python -m http.server 8000
```

или, если установлен Node.js:

```bash
npx serve .
```

Затем откройте в браузере `http://localhost:8000` (для `serve` используйте адрес, который он напишет).

В VS Code можно поставить расширение **Live Server** и нажать «Go Live».

## Где что менять

### Номер телефона для заявок (WhatsApp)

Файл `js/main.js`, самое начало:

```js
const BOOKING_PHONE = "79990000000";
```

Пишите только цифры, с кодом страны, без `+`, пробелов и скобок. Например, `+7 (912) 345-67-89` записывается как `79123456789`.

Там же настраиваются:
- `BOOKING_OPEN_FROM` и `BOOKING_OPEN_TO` — первое и последнее время в списке брони (шаг 30 минут);
- `BOOKING_MAX_GUESTS` — сколько гостей максимум можно указать в форме;
- `SEASON` — продукты и блюда месяцев для «Сезонного круга» на главной.

Телефон, адрес и часы, которые **показываются** на страницах, — это обычный текст в HTML. Его нужно поменять в подвале каждой из пяти страниц (поиск по `000-12-34`), а ещё в `contacts.html` и `booking.html`.

### Цвета

Файл `css/style.css`, блок `:root` в самом начале:

```css
--c-paper: #e6eae3;   /* основной фон */
--c-mist:  #cfd8d0;   /* второй фон, плашки */
--c-ink:   #15302c;   /* текст и тёмные секции */
--c-berry: #6f2639;   /* главный акцент, кнопки, цены */
--c-brass: #b38a45;   /* тонкие линии, фокус */
--c-smoke: #56645f;   /* подписи */
```

Если поменять значение здесь, оно изменится на всём сайте. В SVG-рисунках цвета записаны прямо в атрибутах `fill` и `stroke`. Чтобы перекрасить и рисунки, найдите в HTML-файлах старый код цвета (например, `#6f2639`) и замените его на новый.

Шрифты меняются там же: `--f-display` (заголовки) и `--f-body` (текст). Не забудьте поменять и ссылку на Google Fonts в `<head>` каждой страницы.

### Цены и блюда

Файл `menu.html`. Каждое блюдо — это такой блок:

```html
<li class="dish">
  <div class="dish-head"><h3 class="dish-name">Морс из брусники</h3><span class="dish-dots" aria-hidden="true"></span><span class="dish-price">390&nbsp;₽</span></div>
  <p class="dish-desc">Кувшин 0,5 л. Варим каждый день.</p>
</li>
```

- Цена — внутри `<span class="dish-price">`. `&nbsp;` — неразрывный пробел, чтобы «390» и «₽» не разъезжались по разным строкам.
- Чтобы добавить блюдо, скопируйте блок целиком внутрь нужного раздела.
- Пометка вроде «Фирменное» — необязательная строка `<span class="dish-tag">…</span>`.
- Количество блюд на кнопках фильтра считается автоматически.

Цена дегустационного сета — в `index.html`, ищите `set-price`.

### Пункты меню в шапке

Шапка и подвал одинаковые на всех страницах и продублированы в каждом файле. Если добавляете или переименовываете пункт, сделайте это во всех пяти HTML-файлах. Подсветку текущей страницы задаёт атрибут `aria-current="page"` у нужной ссылки.

## Как выложить на GitHub Pages

1. Зарегистрируйтесь на [github.com](https://github.com) и создайте новый репозиторий (**New repository**), например `restoran-demo`. Сделайте его **Public**.
2. Загрузите файлы одним из способов.
   - **Через сайт:** в репозитории нажмите **Add file → Upload files** и перетащите всё содержимое папки (файлы `*.html`, `README.md`, папки `css` и `js`). Нажмите **Commit changes**.
   - **Через терминал** (в папке проекта):

     ```bash
     git init
     ```

     ```bash
     git add .
     ```

     ```bash
     git commit -m "Демо-сайт ресторана Ольха"
     ```

     ```bash
     git branch -M main
     ```

     ```bash
     git remote add origin https://github.com/ВАШ-ЛОГИН/restoran-demo.git
     ```

     ```bash
     git push -u origin main
     ```
3. В репозитории откройте **Settings → Pages**.
4. В блоке **Build and deployment** выберите **Source: Deploy from a branch**, ветку **main** и папку **/ (root)**, затем нажмите **Save**.
5. Через минуту-две сайт будет доступен по адресу `https://ВАШ-ЛОГИН.github.io/restoran-demo/`.

Файл `index.html` должен лежать в корне репозитория, не во вложенной папке. Иначе GitHub Pages его не найдёт.

## Доступность и адаптивность

- Вёрстка рассчитана на экраны от 320 px. На телефоне меню прячется под кнопку.
- Всё работает с клавиатуры. Фокус хорошо виден (латунная рамка), а первая же клавиша Tab показывает ссылку «Перейти к содержимому».
- Если в системе включено «Уменьшить движение» (`prefers-reduced-motion`), анимации отключаются: бегущая строка останавливается, круг перестаёт вращаться плавно.
- По «Сезонному кругу» можно перемещаться стрелками, а Enter или пробел выбирает месяц.
