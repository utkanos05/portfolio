# «Кобальт» — демо-сайт кофейни

Многостраничный сайт-образец для портфолио. Это вымышленная обжарочная и эспрессо-бар в Москве: кофе, обжаренный вчера, подают в кобальтовом фарфоре. Главное в проекте — проработанные анимации на чистых CSS и JavaScript, без библиотек.

> **Демо-сайт.** Кофейни не существует. Все названия, адреса, телефоны и цены выдуманы.

## Структура

```
kofeinya-demo/
├── index.html      — главная: первый экран, бегущие строки, «капучино прокруткой», обжарка недели
├── menu.html       — меню с анимированным фильтром
├── about.html      — манифест, «путь зерна» (горизонтальная лента), обжарочный аппарат
├── order.html      — предзаказ с живым чеком → WhatsApp с готовым текстом
├── contacts.html   — адрес, статус «открыто/закрыто», нарисованная карта
├── css/style.css   — все стили
└── js/main.js      — весь JavaScript
```

Шрифты с кириллицей подключаются из Google Fonts: Unbounded (заголовки), Onest (текст) и Playfair Display (курсивные акценты). Все изображения нарисованы на SVG и CSS.

## Анимации

| Где | Что происходит |
|---|---|
| Все страницы | Плавный переход между страницами (View Transitions), логотип «перелетает». Шапка прячется при прокрутке вниз и возвращается при прокрутке вверх. |
| Заголовки | Буквы или слова выезжают по одной: атрибут `data-split="chars"` или `data-split="words"`. |
| Блоки | Появляются при прокрутке: `data-reveal` (снизу), `data-reveal="clip"` (шторкой), `data-reveal="scale"` (из маленького). |
| Кнопки | «Магнитные» — тянутся за курсором (класс `magnetic`). При наведении снизу «наливается» второй цвет. |
| Главная | Свечение за курсором, зёрна с параллаксом, пар над чашкой, значок с текстом по кругу, который вращается от прокрутки. Бегущие строки ускоряются и наклоняются при быстрой прокрутке. |
| Главная | **«Листайте — и наливаем»**: пока прокручиваете секцию, стакан наполняется эспрессо, молоком и пеной, а в конце появляется латте-арт. |
| Главная | Шкалы вкуса заполняются, а счётчики «набегают» до своих чисел. |
| Меню | «Таблетка» фильтра переезжает к выбранной кнопке, строки плавно перестраиваются. При наведении строка заливается кобальтом. |
| О нас | Слова манифеста загораются по мере чтения. «Путь зерна» едет вбок при прокрутке вниз (на телефоне это обычный список). Барабан ростера крутится. |
| Предзаказ | Чашка в чеке растёт с объёмом и меняет цвет от молока, сумма «подпрыгивает». Поля с ошибкой встряхиваются. |
| Контакты | Маршрут от метро прорисовывается, метка пульсирует, точка статуса «Открыто» мигает. |

Если в системе включено «Уменьшить движение» (`prefers-reduced-motion`), все анимации отключаются и сразу показывается финальное состояние. Секция с капучино показывает полный стакан, а «Путь зерна» — обычный список.

## Как открыть

Дважды щёлкните по `index.html`. Чтобы сайт работал как на хостинге, запустите локальный сервер в папке проекта:

```bash
python -m http.server 8000
```

Затем откройте `http://localhost:8000`. Переходы между страницами работают в Chrome, Edge и Safari 18+. В остальных браузерах страницы просто открываются как обычно.

## Где что менять

### Номер WhatsApp для заказов

`js/main.js`, первые строки:

```js
const ORDER_PHONE = "79990000000";
```

Только цифры, с кодом страны, без `+`, пробелов и скобок.

Там же:
- `HOURS` — часы работы по дням. По ним считаются статус «Открыто/Закрыто» и время самовывоза.
- `ORDER_DRINKS` — напитки и цены в форме предзаказа.
- `ORDER_SIZES` — объёмы, надбавки к цене и размер чашки в чеке.
- `ORDER_MILK` — виды молока, надбавки и цвет напитка на картинке.

Телефон, адрес и часы, которые **показываются** на страницах, — это текст в HTML. Поменяйте их в подвале всех пяти страниц (поиск по `000-56-78`) и в `contacts.html`.

### Цвета

`css/style.css`, блок `:root` в начале:

```css
--c-porcelain: #f1f2f6; /* фон */
--c-glaze:     #d9dff6; /* светлые плашки */
--c-cobalt:    #1f3fd1; /* главный акцент */
--c-espresso:  #1a1310; /* текст и тёмные секции */
--c-crema:     #e0a458; /* тёплый второй акцент */
--c-ash:       #6b6870; /* подписи */
```

В SVG-рисунках цвета прописаны прямо в атрибутах `fill` и `stroke`. Чтобы перекрасить и их, замените старый код цвета (например, `#1f3fd1`) поиском по всем HTML-файлам.

Скорость анимаций настраивается там же: `--ease-out`, `--t-fast`, `--t-med`, `--t-slow`. Длину секции с капучино задаёт `.pour { height: 400vh; }`: чем больше значение, тем медленнее наливается стакан.

### Цены в меню

`menu.html`, каждая позиция выглядит так:

```html
<li class="item" data-cat="espresso">
  <span class="item-cat">Эспрессо</span>
  <h2 class="item-name">Капучино</h2>
  <p class="item-desc">Описание.</p>
  <span class="item-price">260&nbsp;₽</span>
</li>
```

- `data-cat` — категория: `espresso`, `filter`, `signature` или `bakery`.
- Цена — в `item-price`.
- Пометка вроде «хит» — `<span class="item-tag">хит</span>` внутри названия.

Цены в форме предзаказа задаются отдельно, в `ORDER_DRINKS` в `js/main.js`. Если меняете цену напитка, поменяйте её в обоих местах. Цена пачки зерна на главной — в `index.html`, поиск по `1&nbsp;450`.

## Как выложить на GitHub Pages

1. Создайте на [github.com](https://github.com) публичный репозиторий, например `kofeinya-demo`.
2. Загрузите в него **содержимое** папки: файлы `*.html`, `README.md`, папки `css` и `js`. Можно через **Add file → Upload files** на сайте или через терминал в папке проекта:

   ```bash
   git init
   ```

   ```bash
   git add .
   ```

   ```bash
   git commit -m "Демо-сайт кофейни Кобальт"
   ```

   ```bash
   git branch -M main
   ```

   ```bash
   git remote add origin https://github.com/ВАШ-ЛОГИН/kofeinya-demo.git
   ```

   ```bash
   git push -u origin main
   ```
3. Откройте **Settings → Pages**, в разделе **Build and deployment** выберите **Deploy from a branch**, ветку `main`, папку `/ (root)` и нажмите **Save**.
4. Через пару минут сайт будет доступен по адресу `https://ВАШ-ЛОГИН.github.io/kofeinya-demo/`.

`index.html` должен лежать в корне репозитория, а не во вложенной папке.
