# Портфолио — что где лежит

Откройте **`index.html`** — это оглавление со ссылками на все сайты.

```
портфолио/
├── index.html                      — оглавление всех сайтов
├── 1-новые-многостраничные/         — новые сайты (октябрь 2026), по 5 страниц
│   ├── kofeinya-kobalt/            — кофейня «Кобальт»
│   └── restoran-olkha/             — ресторан «Ольха»
└── 2-старые-одностраничные/         — ранние сайты, каждый в одном файле
    ├── 1-cafe.html                 — пекарня «Мука»
    ├── 2-salon.html                — студия красоты «Лиль»
    └── 3-shop.html                 — керамика «Глина»
```

- **Новые** сайты — это папки. Внутри каждой есть свой `README.md`: как поменять телефон, цвета и цены и как выложить сайт на GitHub Pages.
- **Старые** сайты — одиночные HTML-файлы. Открываются двойным щелчком.
- Новый сайт кладите в `1-новые-многостраничные/` и добавьте строку в `index.html` (в нём есть комментарий, как это сделать).
- `.nojekyll` — пустой служебный файл для GitHub Pages: он просит GitHub выложить файлы как есть. Не удаляйте его.

## Как выложить на GitHub Pages (без программ, через браузер)

1. Зайдите на [github.com](https://github.com), нажмите **+** → **New repository**.
   Название — например, `portfolio`. Выберите **Public**. Галочку «Add a README» **не** ставьте. Нажмите **Create repository**.
2. На странице пустого репозитория нажмите ссылку **uploading an existing file**.
3. Откройте папку `портфолио` в Проводнике, выделите **всё её содержимое** (Ctrl+A) и перетащите в окно браузера.
   Перетаскивать нужно именно содержимое, а не саму папку `портфолио`. Иначе `index.html` окажется не в корне, и сайт не откроется.
4. Дождитесь загрузки файлов и нажмите **Commit changes**.
5. Откройте **Settings → Pages**. В разделе **Build and deployment** выберите **Deploy from a branch**, ветку **main**, папку **/ (root)** и нажмите **Save**.
6. Через 1–2 минуты портфолио откроется по адресу `https://ВАШ-ЛОГИН.github.io/portfolio/`. Ход публикации виден на вкладке **Actions**.

Чтобы обновить сайт позже, снова нажмите **Add file → Upload files** и перетащите изменённые файлы с той же структурой папок. Файлы с такими же путями заменятся.
